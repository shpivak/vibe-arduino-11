# Arduino MEGA2560 — מדריך לילדים

> מדריך פרויקטי ארדואינו למתחילים בגילאי 8–12, עם **ערכת הסטארטר Arduino MEGA2560**.
> גרסה באנגלית: [README.md](README.md)

---

## מה זה?

זה מדריך לבניית פרויקטים מגניבים עם ארדואינו!
כל פרויקט כולל קוד, חיבורים, והסבר פשוט.

---

## ציוד נדרש

- Arduino MEGA2560
- כבל USB (סוג B)
- לוח ניסויים (Breadboard)
- חוטי חיבור (Jumper wires)
- נוריות LED (צבעים שונים)
- נגדים 220Ω
- כפתורים
- בוזר (פסיבי או פעיל)
- סרוו מוטור SG90
- חיישן מרחק HC-SR04
- מסך LCD1602 (עם או בלי מתאם I2C)
- חיישן טמפרטורה ולחות DHT11
- חיישן תנועה PIR
- ג'ויסטיק
- פוטנציומטר
- LED RGB
- מנוע צעד + דרייבר ULN2003

## איך מתחילים?

1. הורד את [Arduino IDE](https://www.arduino.cc/en/software)
2. חבר את הארדואינו למחשב עם כבל USB
3. פתח את קובץ `.ino` של הפרויקט שבחרת
4. בחר **Tools → Board → Arduino Mega 2560**
5. בחר את הפורט הנכון תחת **Tools → Port**
6. לחץ על כפתור ה **Upload** (החץ הימני)
7. תהנה!

---

## כללי בטיחות

- אל תחבר מנועים ישירות לפיני ארדואינו — תמיד השתמש בדרייבר
- תמיד השתמש ב**נגד 220Ω** עם נוריות LED
- אל תחבר ממסר (relay) לחשמל ביתי
- בקש מגדול לעזור לפני חיבור ליותר מ-5V
